👷จัดการรายชื่อช่าง
รายชื่อที่เลือกได้ในช่อง "ช่างที่กำลังทำรายงานนี้" ของฟอร์ม (และใน Dropdown "เลือกชื่อช่าง" ของการ์ดด้านล่างทุกใบ) — ปกติรายชื่อมาจาก Stock (ช่างที่มีของ Spare) กับงานที่เคยมอบหมายใน Admin web เท่านั้น ช่างใหม่ที่ยังไม่มีทั้งสอง อย่างจะไม่มีชื่อให้เลือก เพิ่มชื่อเองได้ที่นี่ ชื่อที่เพิ่มจากหน้านี้ลบได้ ส่วนชื่อที่มาจาก Stock/Admin web ลบจาก หน้านี้ไม่ได้ (ต้องไปแก้ที่ต้นทาง)
🔧จัดการชื่อช่าง (เชื่อมกับ Admin web)
ชื่อในระบบนี้ (เลือกจากลิสต์ — ชื่อเดียวกับที่เลือกได้ในช่อง "ช่างที่กำลังทำรายงานนี้" ตอนกรอกฟอร์ม) → ชื่อที่ใช้ใน Admin web (ตอนมอบหมายงาน) ถ้าสองชื่อนี้ไม่ตรงกัน หน้าฟอร์มจะดึงงานที่มอบหมาย/ของ Spare ของช่างคนนั้นไม่เจอ — แก้ตรงนี้ได้เลยโดยไม่ต้องรอแก้โค้ด (ไม่เกี่ยวกับชื่อที่เขียนลง Track — ดูการ์ด "ชื่อที่เขียนลง Track" ด้านล่างแยกต่างหาก)
📝ชื่อที่เขียนลง Track
เลือกชื่อช่างจากลิสต์ (ชื่อเดียวกับที่เลือกได้ในช่อง "ช่างที่กำลังทำรายงานนี้") แล้วตั้งว่าตอนช่างคนนี้แก้ไขงาน จะเขียนชื่ออะไรลง Track (MDVR/AI Box/ADAS/DMS Tracking) — แยกจากการ์ด "จัดการชื่อช่าง" ด้านบนโดยเจตนา (อันนั้นผูกกับ Admin web อย่างเดียว ไม่เกี่ยวกัน) ชื่อที่ยังไม่ตั้งไว้ที่นี่จะเขียนลง Track ด้วยชื่อดิบตามที่ เลือกไว้ในฟอร์มเลย
💬ชื่ออุปกรณ์ที่เขียนลง LINE
ชื่ออุปกรณ์ที่เลือกได้ในฟอร์ม (จาก catalog ของ Stock) → ชื่อที่จะโชว์ในข้อความ LINE แทน — สำหรับอุปกรณ์ที่ชื่อ ใน catalog ยาว/อ่านยาก แยกต่างหากจากชื่อที่ลงชีต (ดูการ์ด "ชื่ออุปกรณ์ที่เขียนลง Track" ด้านล่าง — จะตั้งให้ เหมือนกันหรือต่างกันก็ได้) อุปกรณ์ที่ยังไม่ตั้งไว้ที่นี่จะใช้ชื่อจากการ์ด "ชื่ออุปกรณ์ที่เขียนลง Track (ชีต)" แทน ถ้าการ์ดนั้นก็ไม่ได้ตั้งไว้ ค่อยใช้ชื่อ catalog ดิบๆ — ตั้งที่นี่เฉพาะตัวที่อยากให้ LINE ใช้ชื่อต่างจากชีต
🏷️ชื่ออุปกรณ์ที่เขียนลง Track (ชีต)
ชื่ออุปกรณ์ที่เลือกได้ในฟอร์ม (จาก catalog ของ Stock) → ชื่อจริงที่จะเขียนลงชีต MDVR Tracking แทน — สำหรับ อุปกรณ์ที่ชื่อใน catalog ไม่ตรงกับชื่อที่ชีตใช้มานาน (เช่นคอลัมน์ Ch ใช้แค่ "DMS"/"ADAS" ไม่ใช่ชื่อรุ่นเต็มๆ) ข้อความ LINE ใช้ชื่อจากการ์ดนี้ด้วย (เว้นแต่ตั้งชื่อเฉพาะสำหรับ LINE ไว้ในการ์ดด้านบน) อุปกรณ์ที่ยังไม่ตั้งไว้ ที่นี่จะใช้ชื่อ catalog ดิบๆ ไปเขียนเหมือนเดิม (ไม่กระทบคอลัมน์ Yes/No เช่น Motor/Buzzer — คอลัมน์พวกนั้นลง "Yes" เสมอไม่ว่าจะตั้งชื่อไว้หรือไม่)
💬ตั้งกลุ่มไลน์ตามช่าง
กำหนดให้รายงานของช่างคนไหน ส่งเข้ากลุ่มไลน์กลุ่มไหน — เลือกชื่อช่างจากลิสต์ (ล็อกไว้ ตรงกับชื่อที่เลือกได้จริงใน ช่อง "ช่างที่กำลังทำรายงานนี้" ของฟอร์ม กันพิมพ์ผิด/ตั้งกลุ่มให้ชื่อที่ไม่มีอยู่จริงเฉยๆ) แล้วใส่ Group ID (พิมพ์ "/กลุ่ม" ในกลุ่มไลน์นั้นๆ เพื่อให้บอทตอบ Group ID มาให้) ช่างที่ยังไม่ตั้งไว้ที่นี่ รายงานจะยังส่งเข้า กลุ่มกลางตามเดิม ส่วนช่างที่ตั้งไว้แล้ว รายงานจะส่งเข้าเฉพาะกลุ่มที่ตั้งไว้เท่านั้น (ไม่ส่งเข้ากลุ่มกลางซ้ำ) — ถ้ารายงานนั้นมีช่างหลายคน (เลือกไว้ในช่อง "ช่างที่กำลังทำรายงานนี้") และแต่ละคนตั้งกลุ่มไว้คนละกลุ่ม ระบบจะส่งเข้าทุกกลุ่มที่เกี่ยวข้องให้อัตโนมัติ
🏢จัดการลูกค้า & Fleet
รายชื่อที่ช่างเลือกได้ในช่อง "ชื่อลูกค้า"/"Fleet" ตอนกรอกรายงาน (ล็อกไว้ — เลือกได้เฉพาะจากลิสต์นี้ พิมพ์ชื่อใหม่เองไม่ได้) — เพิ่ม/ลบรายชื่อได้เฉพาะ Super Admin เท่านั้น ข้อมูลชุดเดียวกับที่ songdee-stock ใช้อยู่
